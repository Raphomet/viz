# Lottie assets

Everything in this folder is original to viz (2026-09-29) and dedicated to the
public domain (CC0 1.0): the Bodymovin JSON animations `lottie1.json` …
`lottie5.json`, the generators `gen-lottie1.mjs` … `gen-lottie5.mjs` that
write them (`node web/assets/lottie/gen-lottieN.mjs`), `kit.js`, and the
Monoline stroke alphabet in `type.js`. No third-party animation or font is
bundled.

The player is lottie-web 5.13.0 (MIT, Airbnb), loaded at runtime from cdnjs:
`https://cdnjs.cloudflare.com/ajax/libs/lottie-web/5.13.0/lottie_light_canvas.min.js`.
